# Статья блога — как заполнять в Tilda

Статья — это товар в разделе каталога «Блог».

| Поле Tilda | Что вписывать |
|---|---|
| **Заголовок** | Заголовок статьи. Идёт в карточку блога и в `<h1>` страницы. |
| **Описание** | Дата и лид через вертикальную черту (см. ниже). |
| **Изображения** | Первое фото — обложка. Она же в карточке блога и под лидом на странице. |
| **Текст** | Тело статьи в HTML. Порядок блоков произвольный. |
| **Разделы каталога** | «Блог». |

Цена, SKU, количество, варианты и опции не нужны.

---

## Поле «Описание»

```
2024-05-10 | Плодородная почва — основа стабильного урожая и здоровых растений. Рассказываем о проверенных природных методах, которые помогают восстановить и поддержать естественное плодородие почвы.
```

До черты — дата (понимается и `10.05.2024`), она же определяет порядок статей: свежие выше.
После черты — лид-абзац под датой. Он выводится только на странице статьи; в карточке блога видна лишь дата.

Если лид не нужен, оставьте только дату.

## Поле «Текст»

Пишется как HTML. Доступные блоки, в любом порядке и количестве:

### Подзаголовок
```html
<h2>Почему важно заботиться о плодородии почвы</h2>
```

### Абзац
```html
<p>Со временем почва истощается: снижается содержание гумуса, полезных микроорганизмов и питательных элементов.</p>
```

### Список
```html
<h2>Естественное повышение плодородия:</h2>
<ul>
  <li>улучшает структуру и аэрацию почвы;</li>
  <li>увеличивает содержание органического вещества;</li>
  <li>способствует развитию полезной микрофлоры;</li>
  <li>снижает потребность в минеральных удобрениях.</li>
</ul>
```

Нумерованный список — `<ol>` вместо `<ul>`.

### Изображение
```html
<img src="https://static.tildacdn.pro/.../photo.jpg" alt="Всходы в поле">
```
Адрес можно взять у любой картинки, уже загруженной в Tilda: откройте её в новой вкладке и скопируйте адрес.

### Видео
Просто поставьте ссылку на YouTube отдельным абзацем:
```html
<p>https://www.youtube.com/watch?v=dQw4w9WgXcQ</p>
```
Страница сама заменит её на превью с круглой кнопкой воспроизведения, как в макете.
Ролик подгружается только после клика, поэтому не замедляет открытие статьи.
Работают все формы адреса: `youtu.be/...`, `youtube.com/embed/...`, `youtube.com/shorts/...`.

### Таблица
```html
<table>
  <tr><th>Культура</th><th>Норма</th></tr>
  <tr><td>Пшеница</td><td>1 л/га</td></tr>
</table>
```

## Сборка страницы `/article`

Сверху вниз:

1. Скрытый блок **«Каталог товаров»** с разделом «Блог» — источник данных.
2. Блок **T123** с `es-article.html`.
3. Блок **T123** с `es-blog.html`, настроенный так:

```js
title: 'Похожие статьи',
limit: 3,
blogUrl: '/blog',
articleUrl: '/article',
excludeCurrent: true,
hideIfEmpty: true
```

Второй скрытый блок-источник для похожих статей не нужен — оба скрипта читают один и тот же.
