# SuperStart — заполнение карточки

Откройте «Каталог товаров» → SuperStart и пройдите поля сверху вниз.

---

## 1. Заголовок

Без изменений:

```
SuperStart
```

## 2. Описание

Замените «Стимулятор всхожести семян» на:

```
Стимулятор всхожести семян. Повышает энергию прорастания и ускоряет появление всходов.
```

Оно выводится под названием на первом экране. Системная страница Tilda это поле не показывает, поэтому скрипт берёт его из карточки в скрытом блоке «Каталог товаров» на странице товара. Если такого блока на странице нет, добавьте первой строкой в «Текст»:

```html
<p class="es-lead">Стимулятор всхожести семян. Повышает энергию прорастания и ускоряет появление всходов.</p>
```

## 3. Текст

Сотрите всё, что там есть, и вставьте блок целиком. В первой части — вкладка «Описание», внутри `<div class="es-tab-specs">` — вкладка «Характеристики».

```html
<ul class="es-cards">
<li data-icon="росток"><b>Стимулирует прорастание</b> Создаёт энергично развивающиеся всходы</li>
<li data-icon="всходы"><b>Ускоряет всходы</b> Способствует более раннему и равномерному появлению всходов</li>
<li data-icon="корни"><b>Развивает корни</b> Стимулирует рост корней, помогая растениям получить больше питательных веществ</li>
<li data-icon="лист"><b>Усиливает побеги</b> Способствует росту побегов и развитию растений</li>
<li data-icon="щит"><b>Снижает стресс</b> Повышает устойчивость растений к стрессам</li>
<li data-icon="рост"><b>Повышает урожайность</b></li>
</ul>

<h2>Состав</h2>
<ul class="es-plus">
<li>Комплекс ростостимулирующих веществ (фульво- и аминокислоты, цитокинины, ауксины, гиббереллины)</li>
<li>Макро- и микроэлементы</li>
</ul>

<div class="es-tab-specs">

<ul class="es-specs">
<li><b>Упаковка</b> флакон 1 л</li>
<li><b>Срок хранения</b> 18 месяцев</li>
<li><b>Условия хранения</b> при температуре 4–30 °C, вдали от прямых солнечных лучей</li>
<li><b>Совместимость</b> совместим со многими агрохимикатами, если производитель не указал иное</li>
</ul>

<h2>Регламент применения</h2>
<table>
<tr><th>Культура</th><th>Норма расхода</th><th>Период обработки, расход рабочей жидкости</th></tr>
<tr><td>Зерновые и масличные культуры, картофель, овощные культуры</td><td>50–150 мл/т</td><td>Обработка семенного материала. Расход рабочей жидкости 10 л/т</td></tr>
</table>

</div>
```

## 4. Изображения

Оставьте фото флакона первым — оно в каталоге и в слайдере.

Если есть баннер или фото применения, загрузите его вторым и вставьте в «Текст» туда, где он должен стоять, например перед `<h2>Состав</h2>`:

```html
<img src="фото 2" alt="Обработка семенного материала">
```

Из слайдера это фото уберётся само.

## 5. Характеристики

Удалите все шесть строк: `упаковка`, `срок хранения`, `условия хранения`, `культура`, `норма расхода`, `период обработки`. Теперь эти данные в «Тексте».

Страница их и так не покажет, раз в тексте есть блок `es-tab-specs`, но с пустым полем в карточке не останется двух версий. Если в каталоге включены фильтры по характеристикам — не удаляйте, фильтры читают только это поле.

## 6. Разделы каталога

Без изменений — `Стимуляторы`.

## 7. Сохранить и проверить

Нажмите «Сохранить и закрыть», опубликуйте страницу и откройте SuperStart на сайте. Должно быть:

| Где | Что |
|---|---|
| Первый экран | название; под ним описание не длиннее двух строк; ссылка «Описание ›»; пункты «Стимулирует прорастание», «Ускоряет всходы», «Развивает корни» |
| Вкладка «Описание» | шесть карточек в две строки по три, раздел «Состав» с двумя пунктами |
| Вкладка «Характеристики» | серый блок из четырёх строк, все значения справа; раздел «Регламент применения» с таблицей |

---

## Что изменилось по сравнению с текущей карточкой

| Было | Стало |
|---|---|
| Условия хранения: 4–18 °C | 4–30 °C, как в PDF. **Сверьте с производителем** — источники расходятся |
| Культура, норма, период — три отдельные строки | одна таблица «Регламент применения» |
| Преимуществ на странице нет | шесть карточек с иконками |
| Состава на странице нет | раздел «Состав» |
