# Модальное окно заявки на странице товара

Окно собирается средствами Tilda: так заявки уходят через уже настроенный сервис Email,
с защитой от спама и сохранением в списке форм. Скрипт страницы товара только подставляет
в него название препарата.

## 1. Создать попап

На странице товара добавьте **Zero-блок** и в его настройках включите режим попапа:
настройки блока → **Тип блока / Показывать как** → **Popup**.
Задайте идентификатор попапа, например `order`.

Внутри соберите окно по макету: заголовок, крестик, три поля и кнопка.

## 2. Заголовок с названием товара

Текст-элемент заголовка (в макете — «Препарат 007-123») пометьте CSS-классом
**`es-popup-title`** в настройках элемента.

Скрипт запишет туда название открытого товара. Что вы напишете в самом элементе
в редакторе — неважно, оно перезапишется при загрузке страницы.

## 3. Поля формы

Элемент Form внутри попапа, поля по макету:

| Поле | Тип | Переменная | Обязательное |
|---|---|---|---|
| Имя | Name | `name` | да |
| E-mail | Email | `email` | нет |
| Телефон | Phone | `phone` | да |

Хотя бы одно из двух — почта или телефон — должно быть обязательным,
иначе придёт заявка, на которую нельзя ответить.

### Скрытое поле с названием товара

Добавьте ещё одно поле: тип **Hidden field**, переменная **`product`**.
Именно в него скрипт подставляет название препарата, и в письме будет видно,
о каком товаре заявка.

Если назовёте переменную иначе, поправьте `productFieldName` в конфиге `es-product.html`.

## 4. Подключить отправку

В настройках формы → **SERVICES** отметьте сервис Email, созданный ранее
в настройках сайта. Привязка нужна отдельно для каждой формы, эта — не исключение.

## 5. Связать с кнопкой

Кнопка «Оставить заявку» на странице товара ведёт по адресу из конфига:

```js
formPopupUrl: "#popup:order",
```

Значение после `#popup:` должно совпадать с идентификатором попапа из пункта 1.
Сейчас там `order` — если назовёте попап иначе, поправьте обе стороны.

## Что придёт на почту

```
product: SuperStart
name:    Ерлан Сагиев
email:   erlan@example.kz
phone:   +7 701 000 00 00
```

Первая строка — название товара, подставленное автоматически.

## Оформление окна

Поля и кнопка внутри попапа подхватят стили из `es-form.html`, если этот блок
стоит на странице товара. Если не ставили — добавьте, иначе форма будет
выглядеть стандартно для Tilda, а не по макету.
