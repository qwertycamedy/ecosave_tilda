# Контактная форма: отправка на почту

Форма собирается элементом Form в Zero-блоке (у вас это `Form 1`).
Отправку писем делает Tilda, писать свой обработчик не нужно.

## 1. Подключить приём данных на почту

Настройки сайта → **Формы** (в некоторых версиях «Сервисы приёма данных») →
**Добавить сервис** → **Email**.

Укажите адрес получателя, например `ecosave.kz@gmail.com`. Можно добавить несколько
адресов через запятую. Сохраните.

Письма уходят с адреса Tilda, поэтому проверьте папку «Спам» после первого теста
и добавьте отправителя в белый список.

## 2. Привязать сервис к форме

В Zero-блоке выделите элемент формы → панель справа → **SERVICES**.
Сейчас там написано «Services not connected». Отметьте созданный Email-сервис.

Это нужно сделать отдельно для **каждой** формы: в секции «Контакты», в блоке
«Записаться на консультацию» и на странице контактов. Сервис общий, но привязка
у каждой формы своя — это самая частая причина, почему одна форма пишет, а другая молчит.

## 3. Проверить поля

По вашим скриншотам поля уже настроены:

| Поле | Тип | Переменная | Обязательное |
|---|---|---|---|
| Имя | Name | `name` | да |
| E-mail или телефон | One line input field | `contact` | нет |
| Сообщение | Multi-line text field | — | нет |

Две правки, которые стоит внести:

Поле `contact` сделайте обязательным — без него заявка бесполезна, ответить некому.
Правило проверки (`VALIDATION RULE`) оставьте `No verification`, потому что поле принимает
и почту, и телефон, а любая проверка отсечёт один из форматов.

Многострочному полю задайте переменную, например `message`. Без неё письмо придёт
с безымянным блоком текста, и в почте будет неудобно читать.

## 4. Сообщение после отправки

В настройках формы задайте текст благодарности либо переход на отдельную страницу.
Без этого посетитель не поймёт, ушла заявка или нет.
