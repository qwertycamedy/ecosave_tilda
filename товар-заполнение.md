# Страница товара — как заполнять в Tilda

Весь контент товара пишется в одном поле **«Текст»** в HTML — так же, как тело статьи блога. Скрипт страницы сам раскладывает его по двум вкладкам:

- всё внутри `<div class="es-tab-specs">…</div>` → вкладка **«Характеристики»**;
- всё остальное → вкладка **«Описание»**.

| Поле Tilda | Куда попадает |
|---|---|
| **Заголовок** | название на первом экране |
| **Описание** | короткий текст под названием, обрезается по двум строкам |
| **Текст** | обе вкладки — «Описание» и «Характеристики» |
| **Изображения** | слайдер; первое фото — ещё и превью в каталоге |
| **Разделы каталога** | категория товара, например «Стимуляторы» |

Поле Tilda **«Характеристики» больше не заполняется.** Если в «Тексте» есть блок `es-tab-specs`, старые значения из этого поля страница не показывает, поэтому ничего не задвоится. Удалить их всё же стоит, чтобы в карточке не было двух версий. Исключение — если в блоке каталога включены фильтры по характеристикам: фильтры читают только поле Tilda.

Цена, SKU, количество, варианты, опции, табы и весовые товары не нужны.

---

## Поле «Описание»

Одно-два предложения о том, что это за препарат. Выводится под названием и обрезается по двум строкам, поэтому главное — в начале.

Под ним автоматически выводятся заголовки первых трёх карточек преимуществ. Если карточек нет — первые три короткие характеристики.

### Чтобы описание появилось на странице

Системная страница товара Tilda поле «Описание» не выводит, поэтому скрипт берёт его из карточки каталога — так же, как статья блога берёт дату и лид. Для этого на странице товара нужен **скрытый блок «Каталог товаров»** со всеми разделами товаров. Если он уже стоит — ничего делать не нужно.

Если блок добавить нельзя, впишите описание первой строкой в «Текст» — оно заменит поле «Описание»:

```html
<p class="es-lead">Стимулятор всхожести семян. Повышает энергию прорастания и ускоряет появление всходов.</p>
```

Если описания нет ни там, ни там, строка под названием просто не выводится, а в консоли браузера (F12) появится подсказка «EcoSave: короткое описание не найдено».

## Поле «Текст»: общая схема

```html
<!-- ===== вкладка «Описание» ===== -->
<ul class="es-cards">…карточки преимуществ…</ul>

<h2>Назначение</h2>
…
<h2>Состав</h2>
…

<!-- ===== вкладка «Характеристики» ===== -->
<div class="es-tab-specs">

<ul class="es-specs">
<li><b>Упаковка</b> флакон 1 л</li>
<li><b>Срок хранения</b> 18 месяцев</li>
</ul>

<h2>Регламент применения</h2>
…

</div>
```

Блок `es-tab-specs` ставьте **в конце** текста. Если забыть закрывающий `</div>`, ничего не сломается: всё после открывающего тега просто уйдёт во вкладку «Характеристики».

### Что куда

| Вкладка «Описание» | Вкладка «Характеристики» |
|---|---|
| Карточки преимуществ | Список характеристик |
| Назначение | Регламент применения — таблица или текст |
| Механизм действия | Порядок приготовления раствора |
| Культуры | Примечания к регламенту |
| Состав | Ограничения совместимости, если длиннее одной фразы |

Порядок разделов одинаковый для всех препаратов, чтобы страницы читались одинаково. Разделов, которых нет в PDF, просто не пишите.

## Блоки HTML

### Как в статье блога

| Блок | HTML |
|---|---|
| Подзаголовок | `<h2>Состав</h2>`, помельче — `<h3>` |
| Абзац | `<p>Текст абзаца.</p>` |
| Жирный, курсив, ссылка | `<b>…</b>`, `<i>…</i>`, `<a href="https://…">…</a>` |
| Изображение по адресу | `<img src="https://static.tildacdn.com/…/photo.jpg" alt="Всходы в поле">` |
| Видео YouTube | `<p>https://www.youtube.com/watch?v=…</p>` — станет превью с кнопкой |
| Таблица | `<table>` … `</table>`, объединение ячеек — `rowspan="3"` |

### Список характеристик

Серый блок «название — значение». Название — в `<b>`, после него значение:

```html
<ul class="es-specs">
<li><b>Упаковка</b> флакон 1 л</li>
<li><b>Условия хранения</b> при температуре 4–30 °C, вдали от прямых солнечных лучей</li>
</ul>
```

Так тоже можно: `<li>Упаковка: флакон 1 л</li>` — название до первого двоеточия. В значении работают `<i>`, `<b>`, `<sup>`.

Значение всегда стоит справа; длинное переносится на несколько строк.

Для всех препаратов один набор, в этом порядке: **Упаковка, Срок хранения, Условия хранения, Совместимость.** Регламент идёт отдельной таблицей ниже в той же вкладке, поэтому норму расхода в список не дублируйте.

### Карточки преимуществ

```html
<ul class="es-cards">
<li data-icon="корни"><b>Развивает корни</b> Стимулирует рост корней, помогая растениям получить больше питательных веществ</li>
<li data-icon="щит"><b>Снижает стресс</b> Повышает устойчивость растений к стрессам</li>
</ul>
```

Заголовки первых трёх карточек попадают на первый экран — держите их короткими, 2–3 слова. Пояснение можно не писать.

Иконки: `лист`, `росток`, `корни`, `щит`, `рост`, `колос`, `почва`, `капля`, `молекула`, `микробы`, `цикл`, `солнце`. Понимаются и синонимы: `всходы`, `защита`, `стресс`, `урожайность`, `урожай`, `азот`, `бактерии`, `грибы`, `разложение`, `погода`. Без `data-icon` ставится лист.

### Списки, шаги, примечания

| Блок | HTML | Для чего |
|---|---|---|
| Список с галочками | `<ul>` | Назначение, Механизм действия, Ограничения |
| Список с плюсами | `<ul class="es-plus">` | Состав, Культуры |
| Шаги с номерами | `<ol>` | Порядок приготовления раствора |
| Примечание в рамке | `<blockquote>…</blockquote>` | «Важно», «Рекомендуем…» |

### Фото из галереи товара

Вместо адреса можно указать номер фото в поле «Изображения»:

```html
<img src="фото 2" alt="Обработка семян">
```

Такое фото выводится в тексте на всю ширину и **убирается из слайдера** — удобно для баннера или схемы. Первое фото (продукт) так не используйте.

```

```

```html
<ul class="es-cards">
<li data-icon="корни"><b>Фиксирует азот</b> Образование клубеньков, которые фиксируют атмосферный азот</li>

<li data-icon="почва"><b>Накапливает азот в почве</b> Аккумуляция почвенного азота</li>
<li data-icon="рост"><b>Повышает урожайность</b></li>
</ul>

<h2>Состав</h2>
<ul class="es-plus">
<li>Живые клетки клубеньковых бактерий <i>Rhizobium leguminosarum</i> с титром не менее 1×10⁹ КОЕ/мл</li>
<li>Полисахариды</li>
<li>Витамины</li>
<li>Фитогормоны</li>
</ul>

<div class="es-tab-specs">

<ul class="es-specs">
<li><b>Упаковка</b> канистра 20 л</li>
<li><b>Срок хранения</b> 6 месяцев</li>
<li><b>Условия хранения</b> при температуре от +1 до +20 °C, максимальная температура хранения +25 °C. Хранить в сухих, вентилируемых помещениях, избегать попадания прямых солнечных лучей</li>

<h3>Порядок приготовления рабочего раствора</h3>

<li>Заполнить ёмкость протравочной машины на 50% водой.</li>
<li>Внести используемые СЗР, следуя рекомендациям производителя.</li>
<li>Инокулянт и протектор внести в рабочий раствор в последнюю очередь.</li>
</ol>

</div>
```

## Active T

**Описание**

```
Биологический фунгицид, стимулятор роста, деструктор. Защищает растения от болезней благодаря профилактическому, лечебному и иммуно-модулирующему действию.
```

**Текст**

```html
<ul class="es-cards">
<li data-icon="щит"><b>Подавляет патогены</b> Подавляет патогенную грибную и бактериальную микрофлору</li>
<li data-icon="цикл"><b>Разлагает остатки</b> Способствует более полному и ускоренному разложению растительных остатков сельскохозяйственных культур</li>
<li data-icon="рост"><b>Усиливает удобрения</b> Повышает эффективность использования минеральных удобрений на 15–30%</li>
<li data-icon="почва"><b>Улучшает почву</b> Улучшает структуру и плодородие почвы</li>
<li data-icon="микробы"><b>Оздоравливает почву</b> Нормализует жизненно важные процессы в почве</li>
</ul>

<h2>Назначение</h2>
<ul>
<li>Улучшение почвенной микрофлоры</li>
<li>Борьба с болезнями почвенного происхождения</li>
<li>Увеличение длины корня</li>
<li>Адаптация устойчивости сельскохозяйственных культур</li>
<li>Деструкция пожнивных остатков</li>
</ul>

<h2>Механизм действия</h2>
<ul>
<li>Гиперпаразит, который подавляет развитие фитопатогенов путём прямого паразитирования, конкуренции за субстрат, выделения ферментов (хитиназы, целлюлазы, глюканазы и других)</li>
<li>Является антагонистом мицелиальных грибков — растительных патогенов; одна из основных функций — способность развивать симбиотические отношения с растениями</li>
<li>Гриб развивается в ризосфере культуры и продуцирует ферменты, которые атакуют и подавляют фитопатогенные грибы</li>
</ul>

<h2>Состав</h2>
<ul class="es-plus">
<li>Штаммы грибов <i>Trichoderma viride</i>, титр не менее 10⁸ КОЕ/мл, и <i>Trichoderma harzianum</i>, титр не менее 10⁸ КОЕ/мл</li>
<li>Продукты метаболизма — биологически активные вещества, улучшающие качество и свойства продукции</li>
</ul>

<div class="es-tab-specs">

<ul class="es-specs">
<li><b>Упаковка</b> канистра 20 л</li>
<li><b>Срок хранения</b> 1 год</li>
<li><b>Условия хранения</b> хранить в сухих, вентилируемых помещениях</li>
</ul>

<h2>Регламент применения</h2>
<table>
<tr><th>Культура</th><th>Расход рабочей жидкости</th><th>Период обработки</th><th>Количество обработок</th></tr>
<tr><td>Зерновые, зернобобовые, масличные, бахчевые</td><td>1 л/т</td><td>Предпосевная обработка семян</td><td>1</td></tr>
<tr><td>Плодово-овощные культуры</td><td>1 л/т</td><td>Предпосевная обработка семян</td><td>1</td></tr>
<tr><td>Зерновые, зернобобовые, масличные, бахчевые</td><td>1–2 л/га</td><td>Обработка в период вегетации</td><td>1–3</td></tr>
<tr><td>Плодово-овощные культуры</td><td>1–2 л/га</td><td>Обработка в период вегетации</td><td>1–5</td></tr>

</div>
```

## Tamyr-NEM

**Описание**

```
Биологический препарат для защиты растений от паразитических нематод.
```

**Текст**

```html
<ul class="es-cards">
<li data-icon="щит"><b>Уничтожает нематод</b> <i>Paecilomyces lilacinus</i> — эндопаразитический гриб, который инфицирует и уничтожает яйца, личинки и взрослых нематод, таких как <i>Meloidogyne spp.</i> и др.</li>
<li data-icon="корни"><b>Защищает корни</b> Применение <i>Paecilomyces lilacinus</i> обеспечивает защиту корней картофеля от повреждений, вызванных активностью нематод</li>
<li data-icon="колос"><b>Повышает урожайность</b> За счёт снижения популяции нематод и защиты корней растений</li>
<li data-icon="лист"><b>Безопасен</b> <i>Paecilomyces lilacinus</i> биологически безопасен для человека и окружающей среды</li>
</ul>

<h2>Назначение</h2>
<ul>
<li>Защита сельскохозяйственных культур от корневых нематод, в том числе корневых узловатых нематод (<i>Meloidogyne spp.</i>), паразитирующих на растениях, и цистообразующих нематод (<i>Heterodera spp.</i> и <i>Globodera spp.</i>)</li>
<li>Стимуляция роста и развития корневой системы</li>
</ul>

<h2>Механизм действия</h2>
<ul>
<li>Грибковые гифы <i>Paecilomyces lilacinus</i> с помощью специальных ферментов проникают в яйца и тело половозрелых корневых нематод-паразитов растений</li>
<li>Затем всё содержимое яйца и тела используется грибком как пищевой ресурс: эмбрион, личинка и органы взрослой особи полностью уничтожаются</li>
<li>Грибок поражает как яйца, содержащие эмбрионы или личинки, так и взрослых нематод</li>
</ul>

<h2>Культуры</h2>
<ul class="es-plus">
<li>Картофель</li>
<li>Овощи открытого и закрытого грунта</li>
<li>Плодово-ягодные (яблоня, груша, виноград, клубника, малина и др.)</li>
<li>Технические (сахарная свёкла, рапс, подсолнечник, соя)</li>
<li>Декоративные деревья и кусты</li>
<li>Комнатные цветочные культуры</li>
</ul>

<h2>Состав</h2>
<ul class="es-plus">
<li>Споры и мицелий штаммов нематофаговых грибов рода <i>Paecilomyces lilacinus</i> с титром не менее 3×10⁹ КОЕ/мл</li>
</ul>

<div class="es-tab-specs">

<ul class="es-specs">
<li><b>Упаковка</b> канистра 20 л</li>
<li><b>Срок хранения</b> 1 год</li>
<li><b>Условия хранения</b> хранить в сухих, вентилируемых помещениях</li>
</ul>

<h2>Регламент применения</h2>
<p>Для обработки гектара земли норма расхода биопрепарата составляет 1–3 литра (расход рабочей жидкости 200–300 л). Биопрепарат применяют для обработки семян овощных и плодовых культур, клубней картофеля, саженцев деревьев и кустарников, а также для обработки культур в период вегетации наземным опрыскивателем, двух- или трёхкратно. На картофеле возможно внесение после посадки, перед гребнеобразованием.</p>

<blockquote><b>Важно:</b> условия жизни хищного гриба схожи с условиями, в которых развивается корневая система растений. Чем ближе препарат попадёт к корню растения, тем надёжнее защита корневой системы. Хищный гриб разрастается и защищает всё больший ареал вокруг корня растения.</blockquote>

</div>
```

## AminoMax

**Описание**

```
Универсальный биостимулятор-антистрессант с повышенным содержанием свободных аминокислот.
```

**Текст**

```html
<ul class="es-cards">
<li data-icon="солнце"><b>Устойчивость к погоде</b> Повышает устойчивость растений к неблагоприятным природным факторам</li>
<li data-icon="корни"><b>Развивает корни</b> Улучшает развитие корневой системы</li>
<li data-icon="росток"><b>Укрепляет иммунитет</b> Повышает иммунитет и степень жизнестойкости растений</li>
<li data-icon="щит"><b>Снимает стресс</b> Улучшает устойчивость растений в условиях стресса</li>
</ul>

<h2>Состав</h2>
<ul class="es-plus">
<li>Общий азот — 7,3%</li>
<li>Свободные аминокислоты — более 20%</li>
<li>Микроэлементы — более 5,0%</li>
</ul>

<div class="es-tab-specs">

<ul class="es-specs">
<li><b>Упаковка</b> канистра 10 л</li>
<li><b>Срок хранения</b> 5 лет</li>
<li><b>Условия хранения</b> при температуре 4–40 °C, беречь от попадания прямых солнечных лучей</li>
<li><b>Совместимость</b> совместим со многими агрохимикатами, если производитель не указал иное</li>
```

## Если что-то не отобразилось

| Что видно | Причина |
|---|---|
| Характеристики оказались во вкладке «Описание» | нет `<div class="es-tab-specs">` или опечатка в классе |
| Вкладка «Описание» пустая, всё в «Характеристиках» | блок `es-tab-specs` открыт в начале текста, а не в конце |
| Характеристики вышли обычным списком с галочками | у `<ul>` нет `class="es-specs"` |
| Карточки вышли обычным списком | у `<ul>` нет `class="es-cards"` |
| Под названием нет описания | на странице нет скрытого блока каталога — см. «Чтобы описание появилось на странице» |
| Теги видны как текст | тег не закрыт: `<b>…</b>`, `<li>…</li>` |
| Фото не появилось | номер в `src="фото 3"` больше, чем загружено изображений |

Если причина не нашлась: откройте страницу товара, F12 → «Консоль», пришлите строки, начинающиеся с «EcoSave».
